# Contributing

This is a portfolio repository, but corrections and documentation improvements are welcome.

Before opening a pull request:

1. Use only public, synthetic, or explicitly redistributable material.
2. Do not submit credentials, real alerts, customer data, private indicators, exploit instructions, complete evaluation fixtures, prompts, or internal implementation details.
3. Attribute third-party material and preserve its license.
4. Label illustrative values and unverified results clearly.
5. Run `./scripts/check-public.sh`.

Security issues should follow [SECURITY.md](SECURITY.md), not a public issue.
