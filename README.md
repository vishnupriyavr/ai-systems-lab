# AI Systems Lab

Public engineering notes for production AI systems in high-stakes workflows.

This repository publishes architecture, decision records, evaluation methods, and sanitized examples. Implementations, complete evaluation sets, prompts, routing heuristics, traces, credentials, and security-control internals remain private.
